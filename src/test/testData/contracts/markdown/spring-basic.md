**接口名称:**

查询用户

**接口描述:**

按编号查询用户。

**请求路径:**

/api/users

**请求方式:**

GET

**请求参数:**

- Header



- Param

|参数名|类型|必选|描述|版本|
|:-----|:-----|:-----|:-----|:-----|
|id|String|Y|用户编号||


- Body



**请求示例:**

```Form
id=null
```

**返回参数:**

|参数名|类型|必选|描述|版本|
|:-----|:-----|:-----|:-----|:-----|
|name|String|N|用户名称||


**返回示例:**

```JSON
{
    "name": ""
}
```
