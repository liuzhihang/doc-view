版本 @@VERSION@@ 更新重点

  1. 01

    生成 HTTP 请求草稿

    为受支持的 Spring/Feign 方法新建可编辑请求，区分请求头、Query、JSON 与表单。生成可取消并保留旧草稿；实际发送需在 IDEA HTTP Client 中主动执行。

  2. 02

    生成与搜索项目文档

    同步生成 Markdown、JSON 摘要索引及结构化接口详情，通过 Export 菜单搜索和打开落盘快照；源码变化后显式更新。正式 MCP 和可安装 Skill 仍是后续计划。

  3. 03

    精简编辑操作与升级 IDE 基线

    采用清晰的图标按钮，支持多行描述和源码写回的一次 Undo/Redo。需要 IDEA IU build 263.7031.23 或更高版本及 Java 25；安装、更新或停用后需重启 IDE。
