HIGHLIGHTS

版本 @@VERSION@@ 更新重点

  1. 01

    实体复制为 Markdown

    Doc Editor 可以把当前说明、必填标记及仍在编辑的单元格复制为 Markdown 字段表，遵循普通或独立分表设置；复制不写回源码。

  2. 02

    文档标签与依赖源码

    接口方法和实体字段支持 @since、@version，已有自定义模板可自行插入新增变量。依赖 JAR 已在 IDEA 关联对应源码时，可读取其字段注释；插件不会自动下载源码。

  3. 03

    路由、参数描述与字段层级

    Spring 路由数组取第一项，支持 path 别名和常量。Javadoc 参数按完整名称匹配并保留多行描述；Markdown 隐藏集合和 Map 的合成中间层，保留真实字段与 JSON 示例。
