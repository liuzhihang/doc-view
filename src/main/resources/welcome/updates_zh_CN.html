  1. 01

    标题与描述各就其位

    类与方法的 Javadoc 标题默认只取首个非空行，可设置 Unicode 字符上限。后续正文独立作为描述，类说明有自己的模板变量，不再挤满目录。

  2. 02

    在同一面板编辑与预览

    模板源码与渲染 Markdown 原位切换，保留草稿和光标。Velocity 变量、指令与 JSON 示例适配当前主题高亮。

  3. 03

    更轻的界面与更稳的预览

    减轻预览边框，增加 GitHub Star 入口并采用平台扫帚图标。列表选择和全部导出使用后台类名快照，避免 UI 回调读取 PSI。
