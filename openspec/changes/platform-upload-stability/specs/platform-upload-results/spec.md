# Spec Delta

## Purpose

明确 Doc View 对三平台上传请求及响应的成功、查无文档、失败和取消判断，使网络异常不会触发误创建或虚假成功，并保持凭据和文档内容不进入错误信息。

## ADDED Requirements

### Requirement: 只有真实查无文档才创建语雀文档
系统 SHALL 仅将语雀文档查询的 HTTP 404 判断为不存在；其他 HTTP/网络/解析失败 MUST 中止该篇上传，不得进入创建或更新。

#### Scenario: 404不依赖正文
- **WHEN** 查询返回 HTTP 404，正文不包含英文 Not Found 或不是 JSON
- **THEN** 系统允许按既有逻辑创建文档

#### Scenario: 查询失败
- **WHEN** 查询返回401、403、429、500或200畸形/空正文
- **THEN** 该篇上传失败，不发送创建或更新请求，不显示成功

### Requirement: 业务成功需要有效响应
系统 MUST 检查 YApi/ShowDoc 的成功代码及当前后续操作必需的返回数据；YuQue查询需有效文档ID，创建/更新需有效ID和slug。空、null、畸形或缺少必需数据的响应 MUST 视为失败。

#### Scenario: 成功与业务错误
- **WHEN** 平台返回有效成功代码及该操作所需数据
- **THEN** 保持既有成功结果和链接语义
- **AND** 非零业务代码或缺少数据时不生成成功结果

### Requirement: 上传传输边界有限且不自动重放
上传 HTTP 请求 SHALL 设置10秒连接/连接池等待和30秒socket读取超时，结束时释放本次客户端和响应资源；系统 MUST NOT 自动重试或跟随重定向发送认证请求。

#### Scenario: 服务重定向或暂时失败
- **WHEN** 当前平台返回重定向、429或500
- **THEN** 本次请求失败且只发送一次，不自动访问Location或重发请求

#### Scenario: 等待网络结束
- **WHEN** 连接或响应读取不能及时完成
- **THEN** 相应超时结束等待并进入错误终态，资源释放

### Requirement: 错误不得包含请求或响应私密数据
HTTP/JSON/业务错误的异常与用户通知 MUST NOT 含请求URL、认证值、payload、原始响应正文或携带这些内容的嵌套cause；可保留平台、阶段及HTTP状态码。

#### Scenario: 响应反射了凭据或业务正文
- **WHEN** 失败正文或畸形JSON包含虚构敏感标记
- **THEN** 异常及其cause链不含该标记，且没有错误正文日志

### Requirement: 保持有效请求协议并正确编码参数
修复 MUST 保持现有平台端点、请求JSON字段和认证位置；查询参数中的字符 SHALL 按URI规则编码而不截断或改变凭据实际值。

#### Scenario: 认证值包含特殊字符
- **WHEN** 虚构YApi token包含空格、加号或与号
- **THEN** 平台接收的单个token参数等于原值，不生成额外查询参数

### Requirement: 取消不转换成普通上传错误
已取消任务 MUST 在后续请求/响应边界停止，不发送后续上传或发布成功；平台上传入口 MUST 透传取消信号给既有后台任务，而非转成失败通知。

#### Scenario: 取消后停止
- **WHEN** 用户取消批量上传或请求开始前任务已取消
- **THEN** 不开始后续网络请求，不显示该取消操作的成功或普通失败通知
- **AND** 已发送请求的远程结果仍需单独核对，系统不承诺回滚
