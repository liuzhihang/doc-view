# Spec Delta

## Purpose

定义 Doc View 项目设置的组织、规则说明和模板编辑反馈，使用户能定位选项、理解配置结果并在提交模板前检查生成内容。

## ADDED Requirements

### Requirement: 项目设置按任务分组
Doc View SHALL 在当前项目的 Settings → Tools 下提供常规行为、生成规则、模板与输出、平台集成四个分组；模板与输出 SHALL 保留参数分表、参数表嵌套层级前缀和合并导出设置；平台集成 SHALL 保留 YApi、ShowDoc、YuQue 各自的设置页面。

#### Scenario: 打开 Doc View 设置
- **WHEN** 用户在已打开的项目中进入 Settings → Tools → Doc View
- **THEN** 用户能分别进入常规行为、生成规则、模板与输出及平台集成设置
- **AND** 平台集成组中能分别打开 YApi、ShowDoc 和 YuQue 设置
- **AND** 模板与输出页分别显示参数分表、嵌套层级前缀和合并导出选项
- **AND** 更改仍只作用于当前项目

### Requirement: 集成凭据清除选项在窄窗口中完整可见
ShowDoc、YApi 和 YuQue 设置页中的凭据清除复选框 SHALL 与对应的密码框保持清楚的视觉关联，并在 900×700 logical Settings 窗口所剩余的设置内容宽度内完整显示本地化标签。清除复选框 SHALL 位于对应密码框的下一行并使用剩余表单宽度；ShowDoc 的 API key 和 API token SHALL 各自拥有独立清除行。密码字段仍 SHALL 保持可用宽度，凭据状态和指南 SHALL 排在凭据输入之后。此布局 SHALL NOT 缩短/隐藏标签或改变凭据语义：空密码表示 Keep，勾选清除表示 Clear，非空密码表示 Replace。

#### Scenario: 在窄窗口查看凭据清除选项
- **WHEN** 用户在 900×700 logical Settings 窗口内打开 ShowDoc、YApi 或 YuQue 页面
- **THEN** 每个凭据清除复选框均位于其对应密码框下方
- **AND** 复选框完整首选宽度处于设置内容区内，完整本地化标签可见且不被裁切
- **AND** 密码框仍有可用输入宽度，ShowDoc 的两个清除选项彼此独立
- **AND** 状态与指南内容仍位于凭据输入之后
- **AND** 用户可观察到的凭据语义、Apply/Reset/Cancel 行为和持久化保持不变
- **AND** 布局验证不读取、填写、清除或应用任何凭据

### Requirement: 生成开关相互独立
行标记选项 SHALL 只控制编辑器中的 Doc View 行标记；普通接口选项 SHALL 控制普通接口的 Doc View 类识别、项目扫描入口和目录展示。任一选项的状态 SHALL NOT 禁用、重置或改写另一选项，也 SHALL NOT 改变各自既有行为范围。

#### Scenario: 关闭行标记但保留普通接口
- **WHEN** 用户关闭行标记并开启普通接口
- **THEN** 设置页仍允许修改并保存普通接口选项
- **AND** 行标记按关闭状态生效
- **AND** 普通接口识别/扫描按开启状态生效，普通接口按既有识别范围进入目录

#### Scenario: 关闭普通接口但保留行标记
- **WHEN** 用户开启行标记并关闭普通接口
- **THEN** 设置页仍允许修改并保存行标记选项
- **AND** 行标记按开启状态生效
- **AND** 普通接口识别/扫描按关闭状态生效，Spring、Feign 与 Dubbo 的既有识别行为保持不变

### Requirement: 选项与生成规则说明一致
设置 SHALL 只展示具有生效行为的选项，并 SHALL 按标题来源、接口名称来源、接口描述来源、必填注释标记和字段名来源组织可配置规则；帮助内容 SHALL 区分可选来源与固定回退/注解规则，并说明来源顺序。

#### Scenario: 浏览生成规则
- **WHEN** 用户打开生成规则设置
- **THEN** 可配置项分别说明四种标题来源、四种接口名称来源、两种接口描述来源、必填注释标记和 `@JsonProperty` 字段名来源
- **AND** 用户能区分可切换规则与不提供开关的固定回退或注解规则
- **AND** 规则启用状态变化不会额外改变已有来源优先级或默认 Markdown

#### Scenario: 以轻量说明阅读生成规则
- **WHEN** 用户在宽窄设置窗口或深浅主题中浏览生成规则
- **THEN** 页面 SHALL 使用分组标题、原生浅分隔线和留白，SHALL NOT 用明显的四边框包围各组
- **AND** 每组 SHALL 仅保留可换行的简短灰色提示，详细来源顺序和固定规则通过组级说明图标提供
- **AND** 说明图标 SHALL 使用 IDEA 原生帮助样式并提供可访问名称和说明
- **AND** 调整 SHALL NOT 改变复选框、来源优先级或 Apply/Reset/Cancel 语义

#### Scenario: 以分行结构阅读问号气泡
- **WHEN** 用户停留在标题、接口名称或接口描述的问号上
- **THEN** 优先级 SHALL 按编号逐条换行显示，回退说明另起短段
- **AND** 必填与字段名帮助 SHALL 按规则主题分段，不只依赖宽度自动折行
- **AND** 可访问描述 SHALL 保留相同的纯文本分行结构

#### Scenario: 查找无效选项
- **WHEN** 用户浏览常规行为或生成规则设置
- **THEN** 页面不展示不改变目录显示或文档生成的隐藏选项
- **AND** 实际生效的参数类型过滤行为保持不变

### Requirement: 模板变量可查阅和插入
模板设置 SHALL 在保留 Spring 与 Dubbo 模板编辑能力的同时提供可搜索的变量说明和插入操作；搜索框 SHALL 展示可见提示并提供无障碍名称。变量列表 SHALL 将属性名与中文标签分行显示；选择变量后，详情区 SHALL 显示完整插入表达式、中文标签和用途/适用性说明，并以可换行方式完整阅读。常规窗口高度下，详情区 SHALL 为这些内容保留约六行可见文本空间；可用高度不足时，详情区 SHALL 可纵向滚动查看余下内容。底部使用提示 SHALL 使用简洁文案，并通过 tooltip 提供完整说明。目录仍可按变量属性名、插入表达式、中文标签或说明搜索，插入操作 SHALL 保留原始完整表达式和当前编辑器目标。此呈现 SHALL 保持原有字号和模板/生成语义；恢复默认 SHALL 只修改当前未提交模板草稿，直到用户应用设置。

#### Scenario: 搜索并插入变量
- **WHEN** 用户在模板设置中按名称或说明搜索变量并选择插入
- **THEN** 选中的变量被插入当前编辑器光标位置
- **AND** 用户可以继续编辑后再应用模板
- **AND** 所选变量的完整说明在独立多行详情中可读，搜索框同时显示提示文字并提供无障碍名称

#### Scenario: 阅读较长变量信息
- **WHEN** 用户选择 `responseParamDataList` 等字段名较长的变量
- **THEN** 列表主行显示简洁属性名，第二行显示对应中文标签
- **AND** 详情区完整显示 `${DocView.responseParamDataList}` 插入表达式和完整用途/适用性说明，内容可以换行而不被列表宽度裁切
- **AND** 常规窗口高度下详情区保留约六行可见文本；可用高度不足时可纵向滚动，且完整用途说明仍可读
- **AND** 底部使用提示显示简洁插入说明，悬停可查看完整说明；原字号、搜索命中和插入原表达式的行为保持不变

#### Scenario: 恢复默认后取消
- **WHEN** 用户恢复默认模板并取消设置对话框
- **THEN** 已保存的 Spring 与 Dubbo 模板保持不变
- **AND** 下次打开模板设置时显示此前已保存的模板

#### Scenario: 恢复默认后应用
- **WHEN** 用户恢复默认模板并应用设置
- **THEN** Spring 与 Dubbo 模板分别保存为随插件提供的默认模板
- **AND** 后续生成继续使用既有模板渲染语义

### Requirement: 模板预览使用固定示例并丢弃过期结果
模板设置 SHALL 允许用户用固定虚构的 Spring 与 Dubbo 示例查看 Markdown 结果；预览 SHALL 在后台生成，且较早请求完成后不得覆盖更新的模板结果。状态 SHALL 明确区分尚未预览、生成中、成功、草稿已变更、空结果和错误；配置页 reset SHALL 清空旧预览并恢复尚未预览状态。预览错误 SHALL 显示可操作的错误信息，并在渲染器提供时显示行列位置。

#### Scenario: 查看 Spring 与 Dubbo 示例
- **WHEN** 用户在模板设置中选择 Spring 或 Dubbo 示例预览
- **THEN** 预览使用插件提供的固定虚构输入并展示 Markdown 源码结果
- **AND** 预览不扫描当前项目源码、不调用外部平台或网络服务
- **AND** 成功结果显示与“尚未预览”不同的完成状态

#### Scenario: 编辑模板并重置配置页
- **WHEN** 用户首次打开或重置模板配置页，之后编辑模板草稿
- **THEN** 首次打开与 reset 后显示尚未预览，编辑后显示预览已过期
- **AND** reset 清除旧结果，编辑不会将旧预览误标为当前草稿结果

#### Scenario: 较早的预览晚于新预览完成
- **WHEN** 用户连续修改模板并触发多次预览，较早请求在较新请求后完成
- **THEN** 页面保留与最新模板草稿对应的结果
- **AND** 较早结果不会替换或清空该结果

#### Scenario: 模板渲染失败
- **WHEN** 当前模板无法渲染
- **THEN** 页面显示失败原因而不把错误内容当作成功 Markdown
- **AND** 渲染器提供行列位置时一并显示

### Requirement: 模板与输出工作区保持低密度
模板与输出设置 SHALL 以“模板编辑”“预览结果”“输出选项”三个页签分隔工作区，首次打开 SHALL 选中模板编辑。模板编辑页 SHALL 保留 Spring/Dubbo 子页签；变量目录 SHALL 默认收起，并可由明确的按钮显示或隐藏。显示变量目录时，编辑器 SHALL 保持可读的最小宽度；用户 SHALL 可通过收起变量目录恢复编辑空间。预览按钮 SHALL 在请求开始时切换到预览结果页签，使生成中、完成、空结果和错误状态均在该工作区呈现；异步结果返回 SHALL NOT 抢占用户后来手动选择的页签。输出选项 SHALL 在独立页签中纵向对齐标签与输入控件，并保留合理间距，不常驻占据编辑或预览区域。

#### Scenario: 首次打开模板设置
- **WHEN** 用户首次打开模板与输出设置
- **THEN** 默认展示模板编辑页，且编辑区保留 Spring 与 Dubbo 两个模板子页签
- **AND** 变量目录处于收起状态，编辑器占据主要工作区域
- **AND** 页头只保留简短说明及原生指南问号；恢复默认操作位于模板编辑工作区，与变量入口同组

#### Scenario: 按需显示模板变量
- **WHEN** 用户点击显示模板变量或收起模板变量
- **THEN** 变量目录按需显示或隐藏，且所选变量仍可插入当前 Spring/Dubbo 编辑器
- **AND** 展开侧栏时编辑器不被压缩到不可读宽度，用户能收起侧栏恢复编辑空间

#### Scenario: 在预览工作区查看渲染状态
- **WHEN** 用户从 Spring 或 Dubbo 模板页点击预览
- **THEN** IDE 立即切换到预览结果页并显示生成中状态
- **AND** 预览成功、空结果或失败状态都显示在该页，用户可通过页签返回模板编辑
- **AND** 如果用户在预览完成前手动切换了页签，异步回调只更新预览内容和状态，不强制切换页签

#### Scenario: 单独编辑输出选项
- **WHEN** 用户切换到输出选项页
- **THEN** 参数分表、两个嵌套层级前缀和合并导出选项纵向分组显示，标签与输入框对齐
- **AND** 编辑、应用、Reset、Cancel 仍遵循当前项目设置的原有草稿与持久化语义

### Requirement: 设置页面支持中英文搜索
Settings 搜索 SHALL 能通过中英文设置名称、选项名称或帮助关键词定位 Doc View 对应页面与选项。

#### Scenario: 使用中英文关键词查找设置
- **WHEN** 用户在 Settings 搜索框输入中文或英文的模板、变量、导出、行标记、普通接口或平台集成关键词
- **THEN** 搜索结果包含对应 Doc View 页面或选项
- **AND** 选择结果后用户能看到对应设置控件

### Requirement: 设置页面提供相关使用指南
Doc View 设置页面 SHALL 以原生问号提供与当前设置主题对应的 GitHub 使用指南入口，悬浮显示简短用途及可点击链接；打开指南 SHALL 不更改设置草稿或已保存值。

#### Scenario: 从模板设置打开模板指南
- **WHEN** 用户从模板与输出设置打开模板帮助
- **THEN** IDE 在默认浏览器打开 GitHub 模板使用指南
- **AND** 当前模板草稿与已保存模板值保持不变

#### Scenario: 从平台集成设置打开集成指南
- **WHEN** 用户从平台集成页或其任一子页打开帮助
- **THEN** IDE 在默认浏览器打开 GitHub 平台集成指南
- **AND** 当前凭据与集成设置值保持不变
