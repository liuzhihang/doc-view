## ADDED Requirements

### Requirement: 共享标题上限紧邻注释来源
系统 SHALL 将唯一的 Javadoc 标题上限输入紧邻类注释来源选项并说明类与方法共用，在方法注释处给出同一上限的关联提示；输入不得悬空在规则分组之间或复制成两套值。默认80、范围1–200、生成语义与保存/取消/校验行为保持不变。

#### Scenario: 在规则页理解与修改上限
- **WHEN** 用户查看类与方法注释来源并修改标题上限
- **THEN** 类注释选项后可立即找到唯一输入，方法选项提示同一上限；Apply 同时作用于类与方法普通标题，Reset/Cancel 不改变已保存值
