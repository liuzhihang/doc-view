# Body Markdown Tables

## Purpose

定义对象字段在普通和分表 Markdown 中的可见层级以及独立实体编辑器的复制结果，使用户阅读真实字段而不暴露解析过程的集合中间节点，同时保留编辑值、生命周期和其他输出的稳定性。

## ADDED Requirements

### Requirement: 容器字段层级
系统 SHALL 在默认字段表隐藏集合 element 与 Map key/value 的合成中间节点，重算真实字段缩进，同时保留实际名为 element/key/value 的业务字段。

#### Scenario: 嵌套容器
- **WHEN** 响应包含 List 对象、Map 对象或这些对象的集合字段，且解析器已生成对应字段树
- **THEN** 普通和分表文档仅展示容器字段与其实际对象字段，没有额外合成层
- **AND** JSON 示例、底层编辑数据、自定义模板结构和上传数据不变

#### Scenario: 标量容器与递归
- **WHEN** 返回标量集合、标量 Map 或递归对象
- **THEN** 不显示无意义的合成键/元素行，不超出既有递归边界

#### Scenario: 未展开的类型
- **WHEN** 类型解析器不能展开某种容器直接嵌套或未解析类型
- **THEN** 保留其既有字段与类型，不把显示层修复解释成新增任意类型解析支持

### Requirement: 独立实体复制 Markdown
系统 SHALL 在独立实体编辑器提供 Markdown 复制操作，复制当前已编辑的字段表，遵循普通/分表设置，不要求先写回源文件。

#### Scenario: 复制当前编辑值
- **WHEN** 实体编辑完成加载，用户编辑描述或必填字段并选择复制 Markdown
- **THEN** 当前单元格编辑提交后将完整字段表复制到剪贴板，含正确嵌套与元数据，源文件不变

#### Scenario: 无可用内容或生命周期结束
- **WHEN** 数据未加载、没有字段、编辑器关闭或项目已释放
- **THEN** 操作不可用或取消，不覆盖剪贴板，不访问无效 PSI
