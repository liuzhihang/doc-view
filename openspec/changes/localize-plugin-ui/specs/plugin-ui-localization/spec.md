# Spec Delta

## Purpose

为 Doc View 的主要设置和操作界面定义可观察的英语及简体中文呈现、语言回退和状态保护，避免界面语言与业务身份、生成内容相互耦合，使用户能以 IDEA 所选语言理解相同功能。

## ADDED Requirements

### Requirement: 插件主要界面跟随 IDE 语言
插件 SHALL 按 IDEA 当前 UI 语言提供英语及简体中文的主要设置、目录状态、菜单、预览/参数编辑弹窗、用户通知和欢迎/更新内容。其它未提供的语言 SHALL 使用英语；SHALL NOT 增加独立语言设置或远程翻译。

#### Scenario: 英语界面
- **WHEN** 用户以英语启动 IDEA 并打开 Doc View 的主要界面
- **THEN** 插件自身的标签、状态、提示和操作说明使用英语，保留产品、注解及用户业务名称
- **AND** 不出现丢失键或未替换占位符

#### Scenario: 简体中文与未支持语言
- **WHEN** 用户以简体中文重启 IDEA
- **THEN** 相同界面使用对应简体中文且功能和入口一致
- **AND** 使用其它语言时插件自身文案回退英语，不宣称支持该语言

### Requirement: 本地化保持业务身份与生成内容
界面翻译 SHALL NOT 改变平台分派、action/configurable 标识、设置字段/值、凭据、模板变量、已有默认模板、已保存模板或生成 Markdown/JSON。用户文本和第三方响应 SHALL NOT 被自动翻译或写回。

#### Scenario: 两种语言选择上传平台
- **WHEN** 用户在任一语言的菜单或弹窗中选择 YApi、ShowDoc 或 YuQue
- **THEN** 相同平台身份交给相同上传服务
- **AND** 取消选择不触发上传、网络请求或设置修改

#### Scenario: 切换语言后生成或编辑模板
- **WHEN** 相同源码和已保存设置在两种语言环境中生成文档或重开模板
- **THEN** 生成结果和模板文本保持一致
- **AND** 只有插件 UI 说明发生翻译，未保存草稿仍遵循 Apply/Reset/Cancel

### Requirement: 规则帮助在两种语言下可读
生成规则 SHALL 保持浅分隔线、短灰字和每组一个原生问号；详细帮助 SHALL 在两种语言下使用合理分段，窄窗口可滚动阅读，不能依赖中文标点拆分或裁切关键优先级。

#### Scenario: 窄窗口阅读帮助
- **WHEN** 用户在较窄设置窗口浏览任一规则并停留于问号
- **THEN** 当前语言的完整来源顺序或必填规则可读，页面短提示可按宽度换行
- **AND** 来源优先级按编号逐条换行，回退另段，固定规则按主题分段；纯文本可访问描述保留分行
- **AND** 说明图标提供同语言可访问名称和描述，不改变规则状态

### Requirement: 本地欢迎内容保持安全导航
英语及简中欢迎/更新内容 SHALL 随包提供，保持相同内部导航目标、主题和安全加载边界；帮助外链 SHALL 仍由默认浏览器打开 GitHub。

#### Scenario: 切换欢迎页语言
- **WHEN** 用户分别在两种 IDEA 语言中打开欢迎页和更新页
- **THEN** 标题、按钮、正文与更新提醒状态使用对应语言
- **AND** 内部导航、CSS、CSP、外链白名单与项目生命周期不变

#### Scenario: 打开公开文档
- **WHEN** 用户从设置指南问号、欢迎页或更新页打开完整指南或变更记录
- **THEN** 系统在默认浏览器打开对应 GitHub `master` 分支的文章、指南目录或 CHANGELOG
- **AND** 英语与简中使用相同目标，旧 `develop` 文档地址不再属于欢迎页外链白名单
- **AND** 导航不应用或丢弃设置草稿，远端正文未发布时由浏览器呈现结果，插件不自动推送或改用其它分支

### Requirement: 模板辅助操作保持轻量且贴近编辑
模板及其它设置页 SHALL 使用原生问号图标提供 GitHub 使用指南，悬浮显示简短用途与可点击链接，恢复默认模板 SHALL 位于模板编辑区的操作行，与变量入口同组；SHALL NOT 使用页头右侧大按钮并排呈现两项辅助操作。两种语言及窄窗口下操作和说明 SHALL 可见且不裁切。

#### Scenario: 编辑与查看模板
- **WHEN** 用户在任一语言中打开模板页或切换预览/输出工作区
- **THEN** 页头为简短可换行说明和原生指南问号，恢复操作只属于模板编辑工作区
- **AND** 恢复仍只更新 Spring/Dubbo 草稿，Apply/Reset/Cancel 语义不变
