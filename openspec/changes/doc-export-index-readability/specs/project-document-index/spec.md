# Spec Delta

## Purpose

项目 API 索引让开发者和工具都能从普通 Markdown 快速定位接口页面与源码，同时保留导出器使用的稳定接口身份。

## ADDED Requirements

### Requirement: 项目 API 索引易于纵向阅读
项目 API 索引 MUST 按模块和类组织为纵向内容，并在每个方法条目中展示可读签名、接口 Markdown 链接和源码链接；完整身份不得占据可读列或强迫读者横向滚动。

#### Scenario: 在编辑器预览中浏览接口目录
- **WHEN** 用户打开生成的 `docs/doc-view/index.md`
- **THEN** 可读区域按模块、类展示方法签名及文档和源码链接
- **AND** 身份哈希和完整身份不会挤压这些可读信息

#### Scenario: 相同输入保持目录顺序
- **WHEN** 用户对相同的项目快照重复生成索引
- **THEN** 模块、类和方法条目的顺序保持稳定

### Requirement: 索引保留稳定机器身份
索引 MUST 为每个方法条目保留可读取的完整 canonical identity 与 SHA-256 元数据，并链接到该身份对应的现有稳定页面文件；重载方法和不同模块的同名方法 MUST 保持可区分。

#### Scenario: 读取完整接口身份
- **WHEN** 工具读取索引中的方法条目
- **THEN** 可从 Markdown 元数据恢复其完整身份字段并验证身份摘要
- **AND** 可读文档链接仍指向对应的稳定接口页面

#### Scenario: 保留重载方法
- **WHEN** 同一类包含参数类型不同的同名重载
- **THEN** 索引显示不同方法签名并分别链接各自页面
