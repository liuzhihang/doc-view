# 1.3.12 internal API 兼容性修复契约

## 变更范围

- 兼容性区域：IntelliJ Platform API 使用。
- 运行时入口：`DocViewStartupNotification`。
- 目标：移除 Marketplace 拒绝的 `PluginManagerCore.getPlugin(PluginId)` 和
  `PluginManager.findEnabledPlugin(PluginId)` internal API 使用。
- 版本来源：由 IntelliJ 扩展框架通过公开的 `PluginAware` 接口注入当前插件的
  `PluginDescriptor`，不再通过插件 ID 查询全局插件列表。

## 外部可观察行为

- 插件启动时仍从当前扩展所属的 `PluginDescriptor` 读取插件版本。
- 当已记录版本低于当前插件版本时，仍展示启动通知并写回当前版本。
- 当已记录版本为空或插件描述符不可用时，保持原有不通知行为。
- 不改变 Markdown 生成、上传、导出、设置持久化、PSI 解析或 UI 可见布局。

## 兼容性边界

- 生产代码不得引用 `PluginManagerCore`、`PluginManager.findEnabledPlugin` 或
  `PluginManager.getPlugin` 获取插件版本。
- 继续支持 IntelliJ IDEA 2026.1；不直接依赖仅在 2026.2 新增的
  `PluginDetailsService`。
- IntelliJ 扩展框架在调用 `runActivity` 前注入描述符；直接构造该类但未注入描述符时，
  启动通知保持静默。

## 验证路径

- 使用源码扫描确认启动通知中不再出现 `PluginManagerCore`、`PluginManager`、
  `findEnabledPlugin` 或插件 ID 查找。
- 运行 `./gradlew test` 验证 Java 编译和现有测试。
- 运行 `./gradlew buildPlugin` 生成 1.3.12 插件包。
- 运行 `./gradlew verifyPlugin` 验证 2026.1 兼容性。
- 使用 Plugin Verifier 1.408 对 Marketplace 报告中的 IntelliJ IDEA 2026.2 RC
  （build 262.8665.176）执行验证，确认不再报告 internal API usage。
- 发布前确认 `gradle.properties` 仍为 `pluginVersion=1.3.12`，且 Marketplace token 不写入仓库。
