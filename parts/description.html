Doc View

Generate Markdown API documentation from Java source code in IntelliJ IDEA.

GitHub · User guide (Chinese) · Issues · Changelog

English

Read Spring Controller, Feign-style and Dubbo interfaces from source, comments and annotations. Preview, copy or export documentation without starting your application or configuring an upload account.

  • Use the first Javadoc line as the class or method title, with a configurable character limit; keep subsequent description lines separately.
  • Browse APIs by module, class and method, then navigate to their Java source.
  • Generate editable HTTP request drafts for supported Spring/Feign endpoints. Send them explicitly from IDEA HTTP Client; generation never sends a request.
  • Edit Spring and Dubbo Markdown templates, insert highlighted variables and switch between source and rendered preview in the same panel. JSON code blocks use theme colors.
  • Export individual or grouped Markdown documents, or generate a project API index with source links and checks for manually edited files.
  • Generate or update project Markdown and JSON documentation together, search the saved API summaries, and open their Markdown files from the Export menu.
  • Use Doc Editor to edit supported field descriptions and required flags, copy entity JSON, or copy current edits as nested or separate Markdown tables without writing them to source.
  • Include method and entity-field @since / @version tags. Read dependency-field comments when matching sources are attached in IDEA; source files are not downloaded automatically.
  • Upload on demand to YApi, ShowDoc or YuQue. Credentials are stored through IDEA PasswordSafe, separately for each project and platform.
  • Use English or Simplified Chinese UI, following the IDE language. Templates and generated documents are not translated automatically.

Find settings under Settings → Tools → Doc View. The template editor, sample output and export options share one content panel; export options have their own view. Compact icons provide preview and variables; the more menu confirms restoring both template drafts. Question-mark icons provide contextual help and links to the online guide.

Help → Doc View Welcome opens the bundled HTML welcome page and update summary in an editor tab. These pages use the IDE's JCEF support and work offline; the full user guide is maintained on GitHub and requires network access.

Custom templates apply to local Markdown and ShowDoc / YuQue content. YApi uses its own structured upload format.

Project documentation is a captured snapshot. Search does not regenerate it; changes to source or templates require an explicit update. Version 1.7.0 adds optional tools for IDEA's built-in MCP Server and Project/Global Codex Skill installation. Automatic Skill installation currently supports macOS Apple Silicon with Codex 0.167.0-alpha.4.1 and requires a compatible official Skill release.

Upgrading from before 1.4.0: re-enter platform credentials in the PasswordSafe-backed settings. Old XML credentials are not imported or automatically removed. OpenAPI 3 field requirements use Schema.requiredMode instead of the deprecated Schema.required. See the credential guide and settings guide for details.

中文

从 Java 源码、注释和注解生成 Spring Controller、Feign 风格接口与 Dubbo 的 Markdown API 文档。 无需启动应用或填写上传账号，即可查看、复制和导出。

  • 类与方法默认以 Javadoc 首行作为标题，可设置字符上限；后续正文独立保留为描述。
  • 按模块、类和方法浏览接口，支持搜索与源码跳转。
  • 为受支持的 Spring/Feign 端点生成可编辑的 HTTP 请求草稿，再由用户在 IDEA HTTP Client 主动执行；生成本身不发送请求。
  • 编辑 Spring、Dubbo 模板，高亮显示并插入变量，在同一内容面板切换源码与固定样例预览，JSON 代码块跟随主题高亮。
  • 单项或批量导出 Markdown，也可生成带源码链接的项目 API 索引，并检查手改文件冲突。
  • 同步生成或更新项目 Markdown 与 JSON 文档，通过 Export 菜单搜索已保存的接口摘要并打开对应 Markdown。
  • 使用 Doc Editor 编辑支持的字段说明与必填信息，复制实体 JSON，或把当前编辑值复制为普通/分表 Markdown；复制不写回源码。
  • 读取接口方法及实体字段的 @since / @version；依赖 JAR 已在 IDEA 关联对应源码时可读取字段注释，不自动下载源码。
  • 按需上传到 YApi、ShowDoc、语雀；凭据由 IDEA PasswordSafe 按项目和平台分别保存。
  • 主要界面支持英语和简体中文，跟随 IDE 语言；模板与生成文档不会自动翻译。

设置入口为 Settings → Tools → Doc View，按常规行为、生成规则、模板与输出、平台集成分类。 模板编辑与渲染预览在同一内容面板切换，右上角图标提供预览和变量操作，更多菜单确认恢复两份默认草稿；输出选项独立展示；问号图标提供就近说明和在线指南链接。

Help → Doc View Welcome 在编辑区打开随包 HTML 欢迎页与更新摘要，依赖 IDE 的 JCEF 支持并可离线查看。 完整使用指南在 GitHub 维护，阅读需要网络。

自定义模板影响本地 Markdown 与 ShowDoc / 语雀正文；YApi 使用独立的结构化上传格式。

项目文档是生成时的快照。搜索不触发生成；修改源码或模板后需显式更新。1.7.0 加入 IDEA 内置 MCP Server 的可选工具，以及当前项目/全局 Codex Skill 安装设置。Skill 自动安装目前支持 macOS Apple Silicon 与 Codex 0.167.0-alpha.4.1，需要兼容的官方 Skill 发行包。

从 1.4.0 之前升级：请在新版设置中重新填写平台凭据，插件不迁移或自动清理旧 XML 密钥。 OpenAPI 3 字段必填使用 Schema.requiredMode，不再读取已弃用的 Schema.required。 具体操作见凭据说明 和设置说明。

Compatibility / 兼容性

Version 1.6.2 requires IntelliJ IDEA IU build 263.7031.23 or later, Java 25, and Java, Markdown and JCEF support. Installation, updates and disabling or removing the plugin require an IDE restart. Exact verified IDE builds are 263.7031.23 and 263.7307.200; future builds are not automatically verified.

1.6.2 需要 IntelliJ IDEA IU build 263.7031.23 或更高版本、Java 25，以及 Java、Markdown 和 JCEF 支持。 安装、更新、停用或卸载后需重启 IDE。本次不承诺热更新或热卸载。 已检查的精确 build 为 263.7031.23 和 263.7307.200，后续版本不自动视为已验证。

See the release record for validation scope and known limitations, including pending native credential failure checks.
